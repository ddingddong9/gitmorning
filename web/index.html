What it does

Five minutes with your coffee, not an hour of scrolling.

A morning brief in the menu bar

Once a day at the time you choose, GitMorning compares today's Trending with yesterday's and shows only what is new or climbing. Projects that match your languages and keywords come first.

Read it in your language

Descriptions and README excerpts are translated on your Mac. Open the full README right in the app, or a translation the project wrote itself.

Keep what caught your eye

Save projects with a note and a status. GitMorning tells you when one of them ships a new release, and exports the list as Markdown.

See what lasts

Streaks show how many days a project has stayed on the list, with its rank for the last week.

Explain it, only if you ask

On Macs with Apple Intelligence, GitMorning can summarize a README in Korean on device. Everything else works without AI.

Privacy

Your list stays on your Mac.

  • No account
  • No analytics
  • No server of its own
  • On-device AI only

Saved projects, notes, translations, and explanations are files in your Library folder. The app reads public pages only: this site's Trending feed, GitHub Trending as a fallback, and the README and release pages of projects you open or save. This site has no cookies or tracking either.

Install

One command.

Homebrew

Opens right away. Updates arrive inside the app, or with brew upgrade.

Or the ZIP

  1. Download it from the latest release and move GitMorning to Applications.
  2. The first time, macOS stops it because GitMorning is not notarized. Choose Done, not Move to Trash.
  3. Open System Settings → Privacy & Security and choose Open Anyway. You only do this once.

Questions

Is it free?

Yes. GitMorning is open source under the MIT license, with no paid plan, ads, or API keys.

Why is it not notarized by Apple?

Notarization needs a paid Apple Developer ID. Updates are still signed with an Ed25519 key and checked before they install, so a tampered update is refused. The source is public.

Which Macs does it run on?

Apple Silicon Macs with macOS 14 or later. Translation needs macOS 15, and Korean explanations need macOS 26 with Apple Intelligence turned on.

Does it need to stay open?

The morning brief and release alerts run while GitMorning is open. Keep it in the menu bar and turn on Open at login, and it is ready every morning.

Where does the list come from?

From github.com/trending. A workflow in the repository collects it several times a day and publishes it on this site; if that copy is older than eight hours, the app reads GitHub directly.

How do I report a bug or help out?

Open an issue or a pull request on GitHub. Korean and English are both welcome.
